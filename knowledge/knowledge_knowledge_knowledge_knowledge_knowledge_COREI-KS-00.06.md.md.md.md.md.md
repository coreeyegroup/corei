# =============================================================================
#
# 1. PURPOSE
#
# =============================================================================

The COREI Knowledge Classification Standard defines the
official classification framework for every Knowledge
Asset within the COREI Knowledge System.

Knowledge classification provides a common institutional
language for understanding the purpose, authority,
responsibility and lifecycle of every Knowledge Asset.

Every Knowledge Asset shall have one primary
classification.



# =============================================================================
#
# 2. OBJECTIVES
#
# =============================================================================

Knowledge Classification exists to

• identify the purpose of knowledge

• establish institutional authority

• support governance

• improve discoverability

• support AI interpretation

• enable deterministic repository organization

• prevent ambiguity

• standardize institutional knowledge



# =============================================================================
#
# 3. CLASSIFICATION PRINCIPLES
#
# =============================================================================

Knowledge classification shall be

Simple.

Deterministic.

Consistent.

Machine-readable.

Institutionally meaningful.

Stable.

Scalable.

Every Knowledge Asset shall belong to exactly
one primary classification.



# =============================================================================
#
# 4. PRIMARY CLASSIFICATIONS
#
# =============================================================================

The COREI Knowledge System recognizes the following
primary classifications.

Constitutional

Defines the permanent institutional foundation
of COREI.

Foundational

Defines institutional models,
systems,
frameworks,
and core structures.

Authoritative

Defines the official institutional source of truth
for a specific subject.

Normative

Defines mandatory rules,
requirements,
standards,
policies,
or specifications.

Operational

Defines how institutional activities
are performed.

Reference

Provides supporting information,
taxonomies,
glossaries,
indexes,
and lookup material.

Historical

Preserves institutional history,
evolution,
and historical records.

Research

Captures investigations,
experiments,
evaluations,
and exploratory knowledge.



# =============================================================================
#
# 5. CLASSIFICATION RESPONSIBILITIES
#
# =============================================================================

Each classification serves one purpose.

Constitutional

Defines identity and permanent principles.

Foundational

Defines institutional structure.

Authoritative

Defines official institutional knowledge.

Normative

Defines mandatory compliance.

Operational

Defines execution.

Reference

Defines supporting information.

Historical

Preserves institutional memory.

Research

Supports institutional learning.

Responsibilities shall never overlap.



# =============================================================================
#
# 6. CLASSIFICATION RULES
#
# =============================================================================

Every Knowledge Asset shall

have one primary classification,

declare its classification,

remain consistent with that classification,

inherit governance appropriate
to that classification,

and maintain its classification
throughout its lifecycle.

Classification changes require
institutional review.



# =============================================================================
#
# 7. AUTHORITY LEVELS
#
# =============================================================================

Knowledge authority generally follows
the following order.

Constitutional

↓

Foundational

↓

Authoritative

↓

Normative

↓

Operational

↓

Reference

↓

Historical

↓

Research

Lower classifications shall not
contradict higher classifications.



# =============================================================================
#
# 8. AI INTERPRETATION
#
# =============================================================================

Knowledge classification enables
artificial intelligence systems to

identify authority,

prioritize retrieval,

resolve conflicts,

understand intent,

and determine appropriate usage.

Classification therefore forms an
essential part of institutional reasoning.



# =============================================================================
#
# 9. CLASSIFICATION GOVERNANCE
#
# =============================================================================

Knowledge classification shall be governed
through the COREI Knowledge Governance framework.

Every classification shall remain

consistent,

traceable,

auditable,

and institutionally approved.

Unauthorized classification changes
are prohibited.



# =============================================================================
#
# 10. AUTHORITY
#
# =============================================================================

The COREI Knowledge Classification Standard
defines the official institutional classification
framework for the COREI Knowledge System.

Every Knowledge Asset,

Knowledge Domain,

Knowledge Foundation document,

engineering standard,

architecture,

AI capability,

workflow,

and operational process

shall declare and maintain one
authoritative classification.

This standard is mandatory throughout
the COREI Knowledge System.
