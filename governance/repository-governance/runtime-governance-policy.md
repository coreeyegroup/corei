# Runtime Governance Policy

## Purpose

Separate mutable operational runtime from institutional source authority.

## Runtime Domains

The following are runtime domains:

- runtime/
- logs/
- reports/
- state/runtime/

These domains:
- are mutable
- are operational
- are replay-driven
- are NOT Git governed

## Operational Principle

Runtime state is ephemeral operational lineage.

It must not pollute release governance.
