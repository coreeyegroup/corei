# Stage 3A — Configuration Foundation

Purpose:
Establish deterministic centralized configuration authority.

This stage governs:
- environments
- strategies
- risk
- brokers
- accounts
- runtime parameters
- feature flags
- snapshots
- lineage

Configuration is:
- versioned
- governed
- validated
- lineage-tracked
- snapshot-controlled

Configuration is NOT:
- hardcoded
- environment-driven runtime state
- manually mutated operational state
