# ADR-002 — Replay-First Governance

## STATUS

Accepted

---

# CONTEXT

Institutional trading systems require deterministic historical reconstruction.

Without replay capability:

- incident analysis collapses
- lineage disappears
- auditability degrades

---

# DECISION

Replay-first governance becomes mandatory platform law.

All critical runtime systems must support deterministic reconstruction.

---

# CONSEQUENCES

## Positive

- deterministic reconstruction
- operational auditability
- forensic analysis capability
- simulation support

---

## Negative

- additional governance overhead
- stricter runtime design constraints

---

# GOVERNANCE

Replay capability is mandatory architectural authority.
