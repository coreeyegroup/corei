Architecture Decision Records
Purpose

Maintain immutable architectural decision history.

Rules
ADRs are append-only
Superseded ADRs are never deleted
All major platform decisions require ADR references
ADR identifiers are immutable
Architectural deviations require new ADR approval
ADR Lifecycle
Proposal
Review
Approval
Implementation
Validation
Supersession (optional)
Naming Convention

ADR-XXX-short-description.md

Example:

ADR-001-kafka-source-of-truth.md
