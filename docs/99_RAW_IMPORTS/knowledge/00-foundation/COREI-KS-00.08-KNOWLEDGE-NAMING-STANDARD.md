# =============================================================================
#
# 1. PURPOSE
#
# =============================================================================

The COREI Knowledge Naming Standard establishes the
official naming conventions used throughout the
COREI Knowledge System.

Its purpose is to ensure that every Knowledge Asset,
directory, identifier, section and reference follows
one consistent institutional language.

Consistent naming enables

clarity,

discoverability,

traceability,

AI interpretation,

and long-term repository stability.



# =============================================================================
#
# 2. OBJECTIVES
#
# =============================================================================

The Naming Standard exists to

• establish one institutional naming language

• eliminate ambiguity

• improve discoverability

• support deterministic navigation

• support AI-native indexing

• standardize repository organization

• preserve naming consistency



# =============================================================================
#
# 3. NAMING PRINCIPLES
#
# =============================================================================

Naming shall be

Simple.

Explicit.

Deterministic.

Consistent.

Readable.

Machine-readable.

Stable.

Scalable.

Names shall describe institutional purpose.

Names shall never depend upon implementation.



# =============================================================================
#
# 4. KNOWLEDGE ASSET IDENTIFIERS
#
# =============================================================================

Every Knowledge Asset shall have one
globally unique identifier.

Standard

COREI-<DOMAIN>-<DOCUMENT>

Examples

COREI-KS-00.08

COREI-ID-01.04

COREI-GV-02.07

COREI-AR-03.11

COREI-EN-04.06

COREI-ST-05.02

COREI-SP-06.08

COREI-OP-07.04

COREI-IM-08.12

COREI-RF-09.03

COREI-HS-10.05

COREI-RS-11.02

Identifiers are permanent.

Identifiers shall never be reused.

#

# =============================================================================
#
# 6. DIRECTORY NAMING
#
# =============================================================================

Knowledge Domain directories shall follow

NN-domain-name

Examples

01-identity

02-governance

03-architecture

04-engineering

05-standards

06-specifications

07-operations

08-implementation

09-reference

10-history

11-research

Directory names shall use

lowercase,

hyphen-separated,

descriptive naming.



# =============================================================================
#
# 7. FILE NAMING
#
# =============================================================================

Knowledge Assets shall follow

COREI-<DOMAIN>-<DOCUMENT>-<TITLE>.md

Examples

COREI-ID-01.01-COREI.md

COREI-ID-01.02-VISION.md

COREI-ID-01.04-PHILOSOPHY.md

COREI-GV-02.03-GOVERNANCE-PRINCIPLES.md

COREI-AR-03.07-ARCHITECTURE-PATTERNS.md

COREI-EN-04.05-ENGINEERING-PRACTICES.md

Filenames are authoritative identifiers.

Filenames shall remain stable.



# =============================================================================
#
# 8. DOCUMENT TITLES
#
# =============================================================================

Document titles shall

describe one responsibility,

use institutional terminology,

avoid abbreviations,

avoid implementation details,

remain stable over time.

Each title shall represent exactly one
Knowledge Asset.



# =============================================================================
#
# 9. SECTION NUMBERING
#
# =============================================================================

Major sections shall use

1.

2.

3.

Subsections shall use

1.1

1.2

1.3

Further nesting shall follow

1.1.1

1.1.2

Numbering shall remain hierarchical
and deterministic.



# =============================================================================
#
# 10. CANONICAL TERMINOLOGY
#
# =============================================================================

Institutional terminology shall remain
consistent throughout COREI.

Canonical terms shall be defined once
within the Reference Domain.

Every Knowledge Asset shall reference
canonical terminology rather than
creating alternative expressions.

Terminology shall remain stable.



# =============================================================================
#
# 11. AI COMPATIBILITY
#
# =============================================================================

Consistent naming enables

semantic search,

knowledge graph construction,

dependency analysis,

cross-domain navigation,

repository indexing,

and deterministic AI reasoning.

Naming consistency is therefore an
institutional requirement.



# =============================================================================
#
# 12. AUTHORITY
#
# =============================================================================

The COREI Knowledge Naming Standard
defines the official naming language
for the COREI Knowledge System.

Every Knowledge Asset,

Knowledge Domain,

repository,

engineering standard,

AI system,

automation workflow,

and future COREI platform

shall comply with this standard.

Changes to naming conventions require
constitutional review.
