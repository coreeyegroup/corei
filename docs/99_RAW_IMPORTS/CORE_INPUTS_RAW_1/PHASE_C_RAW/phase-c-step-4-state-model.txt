	1.2 Phase Role

	Defines the deterministic, replay-safe state system derived strictly from:

		EventLog → State → Snapshot → Output

		materializes system state from events
		guarantees replay equivalence
		enforces hash-chain integrity

		State(t) = f(EventLog[0 → t])

			Replay becomes non-equivalent

			Hidden state risk appears

			State = f(Event Log)
			Replay must be identical

				partition_id

				version_identifiers
			}

				1. partition_id

			- no whitespace variation
			- no optional fields
			- deterministic byte representation mandatory


		output_projection = deterministic mapping:

			output_state = {
				execution_instruction_stream =

				state_hash_reference = state_hash
				snapshot_reference = snapshot_id
			}

			Constraint:

				MUST be pure projection
				MUST NOT introduce new data
