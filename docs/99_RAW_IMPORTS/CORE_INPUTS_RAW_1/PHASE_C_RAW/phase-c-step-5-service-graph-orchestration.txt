5. LOGIC / RULE ENGINE
	5.1 Rule Set

		R1 — Routing Rule
			target_services = routing_map[event.event_type]

		R2 — Graph Resolution Rule

			ServiceGraph MUST be:

				acyclic
				topologically sorted

		R3 — Execution Ordering Rule

			Execution order determined by:

				event_time ASC
				partition_id ASC
				dependency_depth
				service_order (topological)
				event_id ASC

		R4 — Dependency Enforcement Rule

			A task can execute ONLY IF:

				∀ dependency_task ∈ dependency_set:
					dependency_task.status = COMPLETED

		R5 — Partition Consistency Rule

			For same partition:

				strict sequential execution

		R6 — Cross-Partition Coordination Rule

			If dependency across partitions:

				orchestrator MUST block execution until dependency resolved

			(Aligned with Step 3 dependency model )

		R7 — Idempotency Rule

			If task already executed:

				skip execution
				verify output consistency

		R8 — Replay Rule

			Replay MUST reconstruct:

				identical execution_plan
				identical execution order

		R9 — Global Scheduling Tie-Break

			For equal event_time across partitions:

			ordering MUST use:

			1. dependency_depth
			2. partition_id ASC
			3. event_id ASC

		RULE PRECEDENCE (STRICT):

			1. Dependency Resolution (R4)
			2. Partition Ordering (R5)
			3. Global Ordering (R3)
			4. Service Graph Ordering

			No lower rule may override higher rule.

		Execution Infra Replay Rule (MANDATORY)

			Replay MUST reconstruct:

			1. ExecutionOrder stream
			2. OMSRequest stream
			3. EMSInstruction stream
			4. Broker interaction stream

			Constraints:

			- Infra layer MUST be replayed from event logs ONLY
			- No dependency on:

				live services
				broker systems
				system clock

			Replay Modes:

			MODE 1: FULL (with broker events)
			MODE 2: SIMULATION (Step 6 only)

			Both MUST produce identical deterministic outputs

			Violation → SYSTEM NON-REPLAYABLE

	5.2 Execution Order (STRICT)
			Event Intake
			Routing
			Graph Resolution
			Execution Plan Build
			Dependency Resolution
			Task Scheduling
			Service Execution
			State Transition Trigger

			No deviation allowed
