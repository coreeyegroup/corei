1.9 SYSTEM SOFTWARE STACK

	LAYER 1 — BASE SYSTEM (OS)
		Software		: Ubuntu Server 22.04 LTS
		Ownership		: Host machine / VM layer
		Responsibility	: kernel, networking, filesystem, process management
		Why				: Stable, widely supported, K8s native
		Replaceable		: Yes (Debian, RHEL)

	LAYER 2 — CONTAINER RUNTIME
		Software		: 	Docker Engine
		Ownership		: 	Container runtime (ONLY)
		Responsibility	:	build images, run containers, local dev execution
		Why				:	Build + local runtime
		Replaceable		:	Yes (containerd)

			RULE: 	Docker DOES NOT orchestrate production
			Note:	Production uses containerd via Kubernetes internally

	LAYER 3 — CONTAINER ORCHESTRATION
		Software		: 	Kubernetes (K8s)
		Ownership		:	Cluster orchestration layer
		Responsibility	:	deploy services, scale services, service discovery, health checks, networking
		Why				: 	Scaling, orchestration, service control
		Replaceable		:	No (at your scale)

			CRITICAL RULE:
			Kubernetes OWNS runtime orchestration
			Docker ONLY runs containers

		Software		:	Network Policy (Kubernetes-native)
		Ownership		:	service-to-service traffic control,
		Why				:	internal security boundaries
		Replaceable		:	No

	LAYER 4 — PACKAGE MANAGEMENT (K8s)
		Software		: 	Helm
		Ownership		:	Kubernetes package manager
		Responsibility	:	install Kafka, Prometheus, etc., manage deployments as charts
		Why				:	Standard K8s deployment
		Replaceable		: 	Yes (Kustomize)

			RULE:
			Helm ≠ runtime
			Helm = deployment tool ONLY
