1. PHASE IDENTITY LAYER
	1.1 Phase Name

		Phase D — Step 1: Strategy Engine (Execution Interpretation Layer)

	1.2 Phase Role

		Transforms Phase A TradeIntent (logic output) into:

		Execution-ready structured intent

		WITHOUT:

			modifying strategy logic
			introducing new signals
			violating Phase B constraints

	1.3 Phase Objective
		Convert TradeIntent → ExecutionIntent

		- intent is deterministic and constraint-aware

		leakage of execution concerns into Phase A
		ambiguity in trade intent interpretation

5. LOGIC / RULE ENGINE

	5.1 Rules

		R1 — Identity Preservation

			ExecutionIntent.trade_intent_id = TradeIntent.trade_intent_id

		R2 — Size Mapping

			target_size = TradeIntent.size

		R3 — Execution Type Mapping

			execution_type = f(strategy_id, configuration_snapshot)

		R4 — Priority Assignment

			priority_level = TradeIntent.priority_level

		Priority Ownership Rule (MANDATORY)

			priority_level MUST be passed through from Phase A (TradeIntent)

			Phase D MUST NOT:

				compute
				modify
				normalize
				override

			Violation → PHASE INVALID

		Execution Type Mapping Rule

			execution_type = configuration_snapshot.execution_type_map[strategy_id]

			Clamp Rule:

			priority_level ∈ [1,10]

			Out-of-bound → clamp to nearest bound

	5.2 Conditions
		TradeIntent MUST be valid
		Required fields MUST exist

		TradeIntent Validity Contract (MANDATORY)

			TradeIntent is valid ONLY IF:

			- trade_intent_id != NULL
			- instrument ∈ valid_instrument_set
			- direction ∈ {BUY, SELL}
			- size > 0
			- strategy_id != NULL

			Invalid → MUST reject

			No partial acceptance allowed

	5.3 Decision Logic

		No decision branching allowed
		Only deterministic mapping

	5.4 Constraints
		No modification of intent meaning
		No size transformation
		No filtering

	5.5 RULE EXECUTION ORDER
		1. Validate TradeIntent schema
		2. Map identity fields
		3. Map execution parameters
		4. Construct ExecutionIntent

		No deviation allowed

		Rule Precedence (MANDATORY)

			1. Validate TradeIntent (size > 0)
			2. THEN apply mapping

			R2 (size mapping) executes ONLY after validation

			Invalid size → reject before mapping

		EVENT TIME INHERITANCE RULE (MANDATORY)

			ExecutionIntent.event_time MUST be inherited from:

			Phase C event_time

			System clock usage is STRICTLY FORBIDDEN

			Violation → PHASE INVALID
