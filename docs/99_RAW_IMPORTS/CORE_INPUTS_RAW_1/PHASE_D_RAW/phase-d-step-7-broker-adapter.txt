	5.4 Reconciliation Rule (CRITICAL)
		external_fill ≠ internal_fill
		→ external overrides

		reconcile_external_vs_internal():
			input:
				internal_event_stream
				external_fill_stream

			output:
				unified_execution_event_stream

		Reconciliation Safety Constraints:

			Σ(external_executed_size) ≤ order.size

			IF Σ(external_executed_size) > order.size:
			    → HARD FAIL

			remaining_size MUST satisfy:
			    remaining_size = order.size - Σ(external_executed_size)

			remaining_size ≥ 0

		Reconciliation Algorithm (LOCKED):

			Step 1: discard internal fill events
			Step 2: rebuild execution_event_stream ONLY from external_fill_stream
			Step 3: enforce Step 6 lifecycle transitions
			Step 4: emit ORDER_COMPLETED

			No alternative interpretation allowed

		Lifecycle Reconstruction (MANDATORY):

			Reconstructed execution_event_stream MUST include full lifecycle:

			1. ORDER_CREATED
			2. ORDER_ROUTED
			3. PARTIAL_FILL (if applicable)
			4. FULL_FILL (if applicable)
			5. ORDER_COMPLETED

			Rules:

			- ORDER_CREATED MUST be emitted once per order
			- ORDER_ROUTED MUST follow ORDER_CREATED
			- Fill events MUST follow ORDER_ROUTED
			- ORDER_COMPLETED MUST be final event

			Constraint:

			Lifecycle MUST be fully reconstructable from external_fill_stream + ExecutionOrder

		ORDER_CREATED Emission Rule (MANDATORY):

			ORDER_CREATED MUST be emitted from ExecutionOrder initialization.

			normalized_event_time = execution_order.timestamp

			This event MUST be the first event in lifecycle.

		FULL_FILL Determination Rule (MANDATORY):

			cumulative_executed_size = Σ(external_executed_size)

			IF cumulative_executed_size == order.size:
				emit FULL_FILL

			Constraints:

			- FULL_FILL MUST occur exactly once
			- FULL_FILL MUST be the last fill event
			- AFTER FULL_FILL → no further PARTIAL_FILL allowed
			- IF cumulative_executed_size < order.size → FULL_FILL MUST NOT be emitted

		ORDER_ROUTED Emission Rule (MANDATORY):

			IF BrokerResponse.status == ACCEPTED:
				emit ORDER_ROUTED

			IF BrokerResponse.status == REJECTED:
				emit ORDER_FAILED
				STOP further processing

		PARTIAL_FILL Rule (MANDATORY):

			FOR each ExternalFillEvent:

				cumulative_executed_size += executed_size

				IF cumulative_executed_size < order.size:
					emit PARTIAL_FILL

				ELSE IF cumulative_executed_size == order.size:
					emit FULL_FILL

		Upstream Dependency Clarification:

			Step 6 ExecutionEvent stream is considered:

			- SIMULATION ONLY
			- NON-AUTHORITATIVE

			Reconciliation MUST:

			- discard Step 6 fill events completely
			- rebuild from ExternalFillEvent stream

	5.6 Fill Idempotency Rule (MANDATORY)

		Each ExternalFillEvent MUST be uniquely identified using:

		Deduplication Logic:

			IGNORE the event

		- deduplication MUST be deterministic
		- processed_fill_set MUST be reconstructable during replay

	5.7 Time Normalization Rule (MANDATORY)

		External normalized_event_time MUST be normalized before event construction.

		normalized_event_time = MAX(
				ExternalFillEvent.external_event_time,
				execution_order.timestamp
			)

		Constraints:

		- normalized_event_time MUST be monotonic per order
		- normalized_event_time MUST NOT move backward
		- normalization MUST be deterministic
		- identical input MUST produce identical normalized_event_time

		All downstream processing MUST use normalized_event_time.

			normalized_event_time field in:

			- ordering
			- event_id generation
			- lifecycle processing

			MUST be replaced with normalized_event_time.

		normalized_event_time is a derived field and MUST NOT exist in ExternalFillEvent.

			It MUST be computed during normalization phase and used only in:

			- ordering
			- event_id generation
			- lifecycle processing

		Event Time Lineage Rule (GLOBAL — MANDATORY)

			ExecutionEvent.event_time MUST be derived ONLY from:

				trade_intent_snapshot.event_time

			OR

				a deterministic transformation of it (e.g. partial fill sequencing)

			Constraints:

				event_time MUST NOT use:
					- system clock
					- broker timestamp
					- wall-clock time

				event_time MUST preserve ordering consistency with TradeIntent.event_time

			Violation → NON-REPLAYABLE SYSTEM

			Numeric Model Enforcement (MANDATORY — GLOBAL)

						ROUND_HALF_UP

						MUST trigger HARD FAILURE

					underflow:
						treated as zero

				Violation → NUMERIC NON-DETERMINISM
