	5.9 DUAL DECISION MODEL (MERGED — CRITICAL)
		Binary Layer (Invariant)
			IF any FAIL:
				binary_decision = REJECT
			ELSE:
				binary_decision = ACCEPT

		Execution Layer
			IF critical violation:
				execution_decision = BLOCK

			ELSE IF moderate violation:
				execution_decision = MODIFY

			ELSE:
				execution_decision = ALLOW

		Dominance

		Decision Mapping Rule (MANDATORY)

			Constraint:

			binary layer MUST dominate

			execution layer MUST NOT override binary layer
