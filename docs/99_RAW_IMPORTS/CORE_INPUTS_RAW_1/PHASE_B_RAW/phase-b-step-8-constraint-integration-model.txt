	5.3 Constraint Pressure Computation
		Let:

		F = number of FAIL
		M = number of MODIFY
		A = total evaluations

		pressure = (F + α*M) / A

		Where:

		α = deterministic constant ∈ [0,1]

		α MUST be defined in configuration_snapshot:

			α_fp ∈ [0,1]

			Constraint:

			α_fp MUST be fixed-point (scale 10^6)

	5.4 Stability Evaluation
			variance_fp =

					(Σ (x_i - μ)^2 ) / N

				Where:

					x_i ∈ {0,1}
					μ = mean_fp

				All computations MUST use:

					fixed-point scale = 10^6
					INT128 intermediate
					ROUND_HALF_UP

				Ordering:

					sequence index ASC

				Overflow → HARD FAIL

			mean_fp =

					(Σ x_i) / N

				Where:

					x_i ∈ {0,1}
					N = number of observations

				Computation MUST follow:

					INT128 intermediate
					ROUND_HALF_UP
					fixed-point scale = 10^6

			stability_index_fp = 1 - variance_fp

				Constraint:

				variance_fp ∈ [0,1]
				stability_index_fp ∈ [0,1]

	5.5 Violation Trend

		t_i = sequence index (integer)

			Where:

			t_i = i
			i ∈ {1,2,...,N}

			Ordering:

			evaluation_time ASC
			constraint_id ASC

		violation_frequency_fp =

				cumulative_violations / cumulative_observations

			Where:

			values MUST be computed per time index
			using fixed-point arithmetic

	5.6 Invariant Stability Classification
		IF pressure < P1 AND stability_index ≥ S1:
			STABLE

		IF P1 ≤ pressure < P2:
			STRESSED

		IF pressure ≥ P2:
			CRITICAL

	5.7 Constraint Efficiency Score
		useful_constraints =

				constraints WHERE:

					decision_status ∈ {MODIFY, BLOCK}

			efficiency_fp =

				useful_constraints / total_constraints

		IF total_constraints = 0:

			→ REJECT (invalid computation)

	5.8 Determinism Rules
		fixed-point arithmetic ONLY (scale = 10^6)
		ordered evaluation:
			constraint_id ASC
			time ASC
		no stochastic modeling
		no sampling

		ALL statistical computations MUST comply with:

			Phase B Step 6 numeric model:

				scale = 10^6
				INT128 intermediate
				ROUND_HALF_UP

			Functions:

				variance()
				slope()
				mean()

			MUST be explicitly defined using fixed-point arithmetic
