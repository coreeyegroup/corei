	5. EXECUTION STEPS (DETAILED)
		STEP 2.1 — SWAP VALIDATION

			Action

				sudo swapoff -a

			Outcome

				Kubernetes memory model enforced (swap = 0)

		STEP 2.2 — KERNEL MODULES
				sudo modprobe overlay
				sudo modprobe br_netfilter

			Outcome

				Required networking hooks enabled

		STEP 2.3 — KERNEL NETWORK CONFIG
				cat <<EOF | sudo tee /etc/sysctl.d/k8s.conf
				net.bridge.bridge-nf-call-iptables = 1
				net.bridge.bridge-nf-call-ip6tables = 1
				net.ipv4.ip_forward = 1
				EOF

				sudo sysctl --system

			Outcome

				Packet forwarding + iptables routing enabled

		STEP 2.4 — CONTAINERD CONFIGURATION (CRITICAL FIX)
				sudo mkdir -p /etc/containerd

				containerd config default | sudo tee /etc/containerd/config.toml

			Edit:

				sudo nano /etc/containerd/config.toml

			Change:

				SystemdCgroup = true

			Restart:

				sudo systemctl restart containerd
				sudo systemctl enable containerd

			Outcome

				Kubernetes CRI compatibility achieved

		STEP 2.5 — INSTALL KUBERNETES
			sudo apt update

			sudo apt install -y kubelet kubeadm kubectl

		STEP 2.6 — VERSION LOCK
				sudo apt-mark hold kubelet kubeadm kubectl

			Outcome

				Prevents unintended upgrades

		STEP 2.7 — CLUSTER INITIALIZATION
				sudo kubeadm init --pod-network-cidr=192.168.0.0/16

			Outcome

				Control plane created
				Certificates generated
				etcd initialized

		STEP 2.8 — KUBECTL CONFIG
				mkdir -p $HOME/.kube

				sudo cp -i /etc/kubernetes/admin.conf $HOME/.kube/config

				sudo chown $(id -u):$(id -g) $HOME/.kube/config

			Outcome

				Cluster accessible via kubectl

		STEP 2.9 — NODE STATUS CHECK
				kubectl get nodes

			Initial State

				NotReady

		STEP 2.10 — CNI INSTALL (CALICO)
				kubectl apply -f https://raw.githubusercontent.com/projectcalico/calico/v3.27.0/manifests/calico.yaml

			Outcome

				Cluster networking enabled

		STEP 2.11 — SYSTEM POD STABILIZATION
				kubectl get pods -A

			Observed progression:

				Pending → Init → Running

		STEP 2.12 — FINAL NODE VALIDATION
				kubectl get nodes

			Final:

				Ready
