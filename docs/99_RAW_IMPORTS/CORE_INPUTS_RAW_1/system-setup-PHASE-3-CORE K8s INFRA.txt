	5. EXECUTION STEPS (DETAILED)
		STEP 3.1 — INSTALL INGRESS CONTROLLER
			kubectl apply -f https://raw.githubusercontent.com/kubernetes/ingress-nginx/main/deploy/static/provider/cloud/deploy.yaml

			Outcome

				ingress-nginx namespace created
				controller deployed
				admission webhooks installed

		STEP 3.2 — FIX SINGLE NODE SCHEDULING (CRITICAL)
			Problem:

				Pods stuck in Pending due to control-plane taint

			Fix:
				kubectl taint nodes core-node node-role.kubernetes.io/control-plane-

			Outcome

				Workloads allowed on control-plane
				Required for single-node setup

		STEP 3.3 — VERIFY INGRESS
				kubectl get pods -n ingress-nginx

			Outcome

				Running (1/1)

		STEP 3.4 — INSTALL METALLB
				kubectl apply -f https://raw.githubusercontent.com/metallb/metallb/v0.14.5/config/manifests/metallb-native.yaml

			Outcome

				controller + speaker deployed
				CRDs installed

		STEP 3.5 — VERIFY METALLB PODS
				kubectl get pods -n metallb-system

			Outcome

				Running

		STEP 3.6 — DETECT NETWORK RANGE
			ip a

			Observed

				192.168.1.3/24

		STEP 3.7 — CONFIGURE IP POOL
			nano metallb-config.yaml
				apiVersion: metallb.io/v1beta1
				kind: IPAddressPool
				metadata:
				  name: core-pool
				  namespace: metallb-system
				spec:
				  addresses:
				  - 192.168.1.240-192.168.1.250
				---
				apiVersion: metallb.io/v1beta1
				kind: L2Advertisement
				metadata:
				  name: core-l2
				  namespace: metallb-system

			Apply:

				kubectl apply -f metallb-config.yaml

			Outcome

				External IP pool created
				ARP broadcast enabled

		STEP 3.8 — VERIFY LOADBALANCER
				kubectl get svc -A

			Result

				ingress-nginx-controller → EXTERNAL-IP = 192.168.1.240

		STEP 3.9 — INSTALL CERT-MANAGER
			kubectl apply -f https://github.com/cert-manager/cert-manager/releases/download/v1.14.4/cert-manager.yaml

		STEP 3.10 — VERIFY CERT-MANAGER
				kubectl get pods -n cert-manager

			Outcome

				All pods → Running
