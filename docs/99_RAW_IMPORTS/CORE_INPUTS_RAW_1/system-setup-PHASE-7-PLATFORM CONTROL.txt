		STEP 7.2 — VAULT (SECRETS)

			Objective
				Introduce a centralized secrets system to:
					eliminate hardcoded credentials
					securely store secrets (DB, API, keys)
					enable dynamic secret access via Keycloak-issued JWT
					enforce zero-trust access model

			ARCHITECTURAL POSITION
				Service → Keycloak (JWT) → Vault → Secret Access

			DEPLOYMENT MODEL (DOCUMENT-ALIGNED)
				Vault	→ Helm (HashiCorp official chart)
				Mode 	→ Standalone (initial phase)
				Storage → File (ephemeral for now)

			STEP 7.2.1 — ADD REPO
				helm repo add hashicorp https://helm.releases.hashicorp.com
				helm repo update

			STEP 7.2.2 — INSTALL VAULT
				helm install vault hashicorp/vault \
				  -n platform \
				  --set "server.dev.enabled=true" \
				  --set "server.resources.requests.cpu=100m" \
				  --set "server.resources.requests.memory=256Mi"

			STEP 7.2.3 — VERIFY
				kubectl get pods -n platform

				Expected:

					vault-0 → Running
					vault-agent-injector → Running

			STEP 7.2.4 — ACCESS
				kubectl exec -it vault-0 -n platform -- sh
