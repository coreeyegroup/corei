🔴 INITIAL STATE (PROBLEM)
log.dirs = /tmp/kafka-logs ❌

Observed:

ls /tmp/kafka-logs → No such file
ROOT ISSUE
Kafka was writing to ephemeral storage (/tmp)
→ Data loss risk
→ Not production-safe
🔵 FINAL ARCHITECTURE
1️⃣ STORAGE DESIGN
PersistentVolumeClaim (PVC)
→ Mounted at: /var/lib/kafka/data
→ StorageClass: local-path
→ AccessMode: ReadWriteOnce
2️⃣ KAFKA MODE
KRaft Mode (No Zookeeper)
process.roles = broker,controller
3️⃣ CONFIGMAP (Kafka Config)
process.roles=broker,controller
node.id=1
controller.quorum.voters=1@kafka-0.kafka:9093

listeners=PLAINTEXT://:9092,CONTROLLER://:9093
advertised.listeners=PLAINTEXT://kafka-0.kafka:9092

listener.security.protocol.map=PLAINTEXT:PLAINTEXT,CONTROLLER:PLAINTEXT
controller.listener.names=CONTROLLER
inter.broker.listener.name=PLAINTEXT

log.dirs=/var/lib/kafka/data
4️⃣ STATEFULSET DESIGN

Key properties:

volumeMounts:
  - mountPath: /var/lib/kafka/data
    name: kafka-data

volumeClaimTemplates:
  storage: 5Gi
  storageClassName: local-path

if [ ! -f /var/lib/kafka/data/meta.properties ]; then
  kafka-storage.sh format
fi

2️⃣ VAULT (Secrets Management)
Deployment
helm install vault hashicorp/vault --set server.dev.enabled=true
Secrets Engine
vault secrets enable kv-v2
Secret Stored
vault kv put secret/core/db \
  username=postgres \
  password=corepass
VALIDATION
vault kv get secret/core/db ✔
3️⃣ VAULT + KEYCLOAK INTEGRATION (JWT)
AUTH ENABLE
vault auth enable jwt
CONFIG
vault write auth/jwt/config \
  oidc_discovery_url=Keycloak URL \
  bound_issuer=Keycloak issuer
ROLE
vault write auth/jwt/role/core-role \
  role_type=jwt \
  bound_audiences=account \
  user_claim=preferred_username
VALIDATION
vault write auth/jwt/login jwt=<token>
→ token issued ✔
ISSUE ENCOUNTERED
token expired
FIX
Use fresh JWT token

2️⃣ FAILURE SCENARIO PLAYBOOK

(Production Troubleshooting Guide)

🔴 CATEGORY A — CLUSTER / INFRA FAILURE
❌ SYMPTOM
Pods → Evicted / Pending
kubectl top → not working
ROOT CAUSE
• Memory pressure
• Disk pressure
• No resource limits
ACTION
kubectl get nodes
kubectl describe node

kubectl scale deployment <heavy-service> --replicas=0
kubectl delete pod <evicted> --force --grace-period=0
PREVENTION
✔ Always define resources (requests + limits)
✔ Monitor node usage
✔ Deploy observability early
🔴 CATEGORY B — KAFKA FAILURE
❌ SYMPTOM
No events flowing
Topics empty
CHECK
kubectl exec -it kafka-0 -n kafka -- \
/opt/kafka/bin/kafka-console-consumer.sh \
--topic validated_events \
--bootstrap-server localhost:9092
ROOT CAUSE
• Wrong log.dirs
• PVC not mounted
• Broker restart without storage
FIX
✔ Ensure log.dirs=/var/lib/kafka/data
✔ PVC bound
✔ meta.properties exists
🔴 CATEGORY C — STORAGE FAILURE
❌ SYMPTOM
DB connection fails
Queries slow
CHECK
kubectl get pods -n storage
kubectl exec -it timescaledb-0 -- psql
ROOT CAUSE
• PVC issue
• Extension missing
• Memory pressure
FIX
CREATE EXTENSION IF NOT EXISTS timescaledb;
🔴 CATEGORY D — AUTH FAILURE
❌ SYMPTOM
401 Unauthorized
invalid_grant
ROOT CAUSE
• Wrong grant type
• Token expired
• Client misconfigured
FIX
grant_type=client_credentials
VAULT FAILURE
error validating token
FIX
✔ Check bound_issuer
✔ Use fresh JWT
✔ Verify OIDC URL
🔴 CATEGORY E — METRICS FAILURE
❌ SYMPTOM
kubectl top node → not working
ROOT CAUSE
metrics-server misconfigured
FIX
--kubelet-insecure-tls
--kubelet-preferred-address-types=InternalIP
--kubelet-use-node-status-port

❌ SYMPTOM
InvalidImageName
ImagePullBackOff
ROOT CAUSE
Invalid image / private registry
FIX
✔ Use valid image
✔ Check imagePullSecrets
