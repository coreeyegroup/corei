01 Executive Summary

Phase‑04 implements the institutional Provider Platform – a unified abstraction layer for replaceable runtime engines embedded inside COREI OS. It includes the generic Provider Foundation, UI Provider Platform, lifecycle management, registry, runtime, and six concrete provider implementations: Monaco (editor), Dockview (workspace), xterm.js (terminal), AG Grid (enterprise grid), Apache ECharts (visualization), and React Flow (graph/workflow). This platform ensures that all vendor technologies are isolated behind COREI contracts, enabling replaceability and vendor independence.

03 Architecture

The Provider Platform is layered to separate generic provider infrastructure from UI specialization and concrete implementations.

LayerResponsibility
Generic Provider PlatformContracts, models, registry, runtime, manager for all providers
UI Provider PlatformSpecialized contracts, lifecycle, registry, runtime, manager for UI providers
Concrete UI ProvidersMonaco, Dockview, xterm.js, AG Grid, ECharts, React Flow implementations

Dependency Flow

Phase-01/02/03 → Provider Platform → UI Provider Platform → Concrete Providers → Vendor Libraries

Institutional Separation

  • Foundation frameworks (React, Tailwind, Zustand, etc.) are NOT providers – they belong to the future Foundation Platform.
  • External systems (Kubernetes, Kafka, Grafana, etc.) are NOT providers – they belong to the future Integration Platform.
  • Provider Platform owns ONLY replaceable runtime engines.
