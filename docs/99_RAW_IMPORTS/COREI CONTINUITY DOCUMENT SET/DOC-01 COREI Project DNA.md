# =============================================================================
# CHAPTER 01
#
# WHAT IS COREI
#
# =============================================================================

COREI is NOT

• Dashboard

• Trading Terminal

• Broker Software

• Portfolio Tracker

• Charting Platform

• Monitoring Tool

• IDE

• ERP

COREI IS

An Institutional Operating System.

Its responsibility is to become the single operational environment from which an
institution operates every aspect of trading and technology.

Instead of opening many independent software products,

the operator should open COREI.

Everything else becomes a capability inside COREI.

The platform must feel like an Operating System rather than an application.

#
