01 Executive Summary

This phase builds the permanent institutional shell environment for COREI OS. It provides a full‑screen workstation with six regions, runtime, lifecycle, keyboard commands, persistence, instrumentation, and resilience.

03 Architecture

The Shell follows a layered architecture with clear separation of concerns.

LayerResponsibility
PresentationReact components (Shell, ShellFrame, ShellBoundary, ShellRegion)
OrchestrationShellManager, ShellRuntime, ShellLifecycle
StateShell state (lifecycle, ready, operational)
EventsShell events (initializing, started, stopped, failed)
ContractsShellKernelContract, ShellLayoutContract, ShellRegionContract
PersistenceVersioned snapshots, localStorage adapter
InstrumentationLogging, diagnostics, health reporting

Startup Flow

main.tsx → App → ShellBoundary → ShellProvider → ShellManager.init → ShellLifecycle.init → ShellRuntime.init → restore → keyboard init

Keyboard Command Flow

Keydown → ShellKeyboardRuntime → ShortcutResolver → CommandRouter → InteractionRuntime → WorkbenchStateManager → Workbench State

Persistence Flow

Startup: restore → set visibility from snapshot
Disposal: save → localStorage
On toggle: toggle → WorkbenchStateManager → save
