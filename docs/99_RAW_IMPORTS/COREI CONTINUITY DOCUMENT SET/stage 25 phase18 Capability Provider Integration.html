01 Executive Summary

Phase‑18 implements the Capability Provider Integration boundary – the deterministic layer that connects the completed COREI Capability Platform to the approved Provider Platform. It establishes provider binding, resolution, lifecycle integration, runtime integration, failure/health/availability evaluation, and a composed integration entry point. The phase also delivers 14 operator‑facing Workbench panels that expose capability and provider runtime state, relationships, lifecycle, health, availability, and diagnostics through the existing Institutional Shell.

03 Architecture

The Phase‑18 backend follows the certified integration pipeline:

LayerResponsibility
BindingCapability ↔ Provider relationship, priority, enabled flag
ResolutionDeterministic selection of enabled binding with priority and lexical tie‑break
Lifecycle IntegrationProvider lookup, lifecycle eligibility (ACTIVE only)
Runtime IntegrationRuntime readiness (initialized + loaded)
Operational IntegrationFailure, health (Foundation Health), availability evaluation with deterministic precedence
CompositionOrchestrates all stages into a single public integration entry point

UX Architecture

The UX panels consume the backend integration through adapters and are registered in the existing Workbench panel catalog. They are displayed within the Phase‑17 Institutional Shell without modifying shell ownership.
