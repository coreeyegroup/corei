# PORTFOLIO AUDIT GOVERNANCE

## AUTHORITATIVE AUDIT LAW

All financial state must remain:
- replay-safe
- reconstructable
- lineage-verifiable

## REPLAY GOVERNANCE

Replay(state_t) == Original(state_t)

## HASH GOVERNANCE

Replay hash equality mandatory.

## CAPITAL GOVERNANCE

No capital bleed permitted between partitions.

## FINANCIAL GOVERNANCE

All financial arithmetic:
- BIGINT
- deterministic
- fixed-point

FLOAT prohibited.
