# LIVE_AUTO Governance

## Purpose

LIVE_AUTO enables controlled autonomous execution.

This mode:
- permits unattended execution
- permits autonomous order routing
- permits autonomous strategy execution

ONLY under:
- institutional governance
- semantic governance enforcement
- operational lineage continuity
- strict operational containment

---

# Operational Constraints

LIVE_AUTO is restricted to:
- one broker
- one account
- one strategy
- small capital allocation

Scaling is forbidden until:
- operational stability is proven
- governance continuity is proven
- autonomous execution stability is proven

---

# Governance Requirements

LIVE_AUTO requires:
- Stage 17 validation pass
- Stage 19 recovery validation pass
- LIVE_SEMI observation certification
- semantic governance certification
- operational stability certification

---

# Institutional Principle

Autonomous execution is a privilege earned through:
- operational reliability
NOT:
- strategy profitability
