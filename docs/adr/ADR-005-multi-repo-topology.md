# ADR-005 — Transitional Multi-Repository Topology

## STATUS

Accepted

---

# CONTEXT

Corei currently operates under a transitional multi-repository model.

Premature monorepo convergence introduces governance instability.

---

# DECISION

Repository separation remains temporarily authoritative.

The governance root remains operational authority.

Repositories remain implementation authorities.

---

# CONSEQUENCES

## Positive

- isolated ownership
- bounded deployment domains
- operational clarity

---

## Negative

- additional repository coordination
- CI complexity

---

# GOVERNANCE

Topology convergence must remain governance-driven.

Premature flattening is prohibited.
