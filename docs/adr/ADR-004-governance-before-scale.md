# ADR-004 — Governance Before Scale

## STATUS

Accepted

---

# CONTEXT

Institutional systems collapse when implementation scale exceeds governance maturity.

---

# DECISION

Governance layers must precede runtime scaling.

Filesystem governance, deployment governance, replay governance, and ownership governance are mandatory before runtime expansion.

---

# CONSEQUENCES

## Positive

- reduced architectural entropy
- operational consistency
- deterministic evolution

---

## Negative

- slower early implementation velocity

---

# GOVERNANCE

Governance stability takes precedence over implementation speed.
