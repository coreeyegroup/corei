# PORTFOLIO GOVERNANCE LAWS

## LAW-01 — PORTFOLIO AUTHORITY

portfolio-service is authoritative financial truth.

## LAW-02 — EVENT-DERIVED STATE

State derives ONLY from Kafka event lineage.

## LAW-03 — SNAPSHOT DERIVATION

Snapshots are derived state only.

## LAW-04 — REPLAY CERTIFICATION

Replay output must equal original output.

## LAW-05 — FLOAT PROHIBITION

FLOAT financial arithmetic prohibited.

## LAW-06 — CAPITAL ISOLATION

No capital bleed permitted between partitions.

## LAW-07 — LINEAGE RECONSTRUCTION

All portfolio state must be reconstructable from event lineage.
