# LIVE_SEMI Governance

## Purpose

LIVE_SEMI enables supervised real-money execution.

This mode:
- permits real order preparation
- permits real execution requests
- requires explicit human approval for every trade

This mode does NOT:
- permit autonomous execution
- permit unattended execution
- permit LIVE_AUTO behavior

---

# Governance Constraints

LIVE_SEMI requires:
- semantic governance certification
- Stage 17 validation pass
- Stage 19 recovery validation pass
- broker onboarding completion

---

# Human Supervision Model

Each execution request requires:
- human review
- explicit approval
- operational audit lineage

All approvals become:
- audit events
- operational lineage records
- governance-traceable actions

---

# Operational Restrictions

The following remain prohibited:
- unattended execution
- autonomous execution
- multi-account activation
- multi-strategy scaling
