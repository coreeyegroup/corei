# CORE EYE RESEARCH GOVERNANCE

This directory contains the institutional research governance layer.

Principles:
- all datasets versioned
- all features versioned
- all backtests reproducible
- all promotion decisions traceable
- no ad hoc production promotion

Research Flow:
research
→ backtest
→ validation
→ walk-forward
→ paper trade
→ staging approval
→ production promotion

Every strategy must reference:
- dataset version
- feature version
- governance approval state
