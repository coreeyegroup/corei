# COREI Spacing Architecture

Version: 1.0
Status: FROZEN

========================================
PURPOSE
========================================

Define spacing standards for all COREI terminals.

Spacing must be tokenized.

No arbitrary spacing values allowed.

========================================
SPACING HIERARCHY
========================================

XS

SM

MD

LG

XL

XXL

========================================
USAGE
========================================

XS

Micro spacing.

----------------------------------------

SM

Internal component spacing.

----------------------------------------

MD

Component separation.

----------------------------------------

LG

Section separation.

----------------------------------------

XL

Workspace separation.

----------------------------------------

XXL

Major layout separation.

========================================
DENSITY MODES
========================================

Compact

Standard

Comfortable

========================================
RULES
========================================

All spacing must use tokens.

No hardcoded spacing values.

Spacing controls density.
